# Digital Aid Seattle Design System

Components for the Digital Aid Seattle website, built from the Figma style guide and grown by prompt.

- **Tokens** live in `src/tokens/tokens.css`. Every color, font, radius and spacing value comes from there.
- **Components** live in `src/components/<Name>/`: the component, its stories, and an `index.ts`.
- **Breakpoints**: Small (under 600px), Medium (600–960px), Large (960px and up). Use the viewport menu in the toolbar to preview each.
- **Backgrounds**: switch between Light and Dark green in the toolbar.
